**Agent operations (SQL patterns):**

1. **Read my open tasks:**
   `SELECT task_code, title, priority, depends_on, status_notes FROM agent_tasks WHERE agent_role = '@<MY_ROLE>' AND status IN ('open','blocked') ORDER BY CASE priority WHEN 'critical' THEN 1 WHEN 'high' THEN 2 WHEN 'medium' THEN 3 ELSE 4 END`

2. **Mark task completed:**
   `UPDATE agent_tasks SET status = 'completed', status_notes = '<findings/output>', completed_date = NOW(), updated_at = NOW() WHERE task_code = '<TASK_CODE>'`

3. **Mark task in-progress:**
   `UPDATE agent_tasks SET status = 'in_progress', updated_at = NOW() WHERE task_code = '<TASK_CODE>'`

4. **Add status notes:**
   `UPDATE agent_tasks SET status_notes = COALESCE(status_notes, '') || E'\n' || '<new note>', updated_at = NOW() WHERE task_code = '<TASK_CODE>'`

5. **Read CEO directives:**
   `SELECT directive_date, directive FROM ceo_directives WHERE is_active = TRUE ORDER BY directive_date DESC`

6. **Cross-team dashboard:**
   `SELECT agent_role, COUNT(*) FILTER (WHERE status='completed') as done, COUNT(*) FILTER (WHERE status IN ('open','in_progress')) as open, COUNT(*) as total FROM agent_tasks GROUP BY agent_role ORDER BY agent_role`

7. **Write daily rollup (@pm only):**
   `INSERT INTO status_updates (update_date, agent_role, update_type, summary, tasks_completed, tasks_assigned, blockers, human_attention, critical_path) VALUES (CURRENT_DATE, '@pm', 'daily_rollup', '<summary>', '<completed>', '<assigned>', '<blockers>', '<attention>', '<critical_path>')`

8. **Assign new task (@pm, @data-planner):**
   `INSERT INTO agent_tasks (task_code, agent_role, title, status, phase, priority, depends_on, assigned_by, assigned_date) VALUES ('<CODE>', '<@ROLE>', '<TITLE>', 'open', '<PHASE>', '<PRIORITY>', '<DEPENDS>', '<@ASSIGNER>', CURRENT_DATE)`

**Status values:** `open` | `in_progress` | `completed` | `blocked`
**Priority values:** `critical` | `high` | `medium` | `low`
